# 小泰福福 IB 36 分衝刺表

2026/9/20 – 2027/4/25 每日練習進度：英文 A、經濟 HL、化學 HL、物理 SL、數學 AA HL。
模擬考 2027/3/15｜IB 大考 2027/4/26｜成績公布 2027/7/6

網址：<https://nokosii.github.io/ibexam/>

## 每天怎麼用

- 每科列出當天指定的 exam-mate 題目代碼（例：`MathAA/11_HL_Summer_2024_Q2`）。按「打開 exam-mate」進入該科，用 Year、Season、Paper 篩選後找到代碼作答。
- 化學、物理有些題目來自舊版課綱（代碼開頭 `CHEMI/`、`PHYSI/`），請用「舊版」連結。
- 寫完對照 Answer 自己訂正，把作答紙拍照或截圖，按「上傳練習截圖」（可一次多張）。上傳後自動勾選完成，顯示「等待家長確認」。
- 家長按「家長模式」輸入密碼，對照指定題目檢視截圖，按「確認完成」或「需要訂正」並留言；也可刪除傳錯的截圖。
- 任務若註明「含已做過的題目，請重做」，代表題庫不夠，請把之前做過的題再做一次。

## 資料存在哪裡

- 勾選、備註：Google 試算表 `progress` 工作表
- 截圖：Google 雲端硬碟「IB 每日練習截圖」資料夾；清單在 `shots` 工作表
- 家長確認：`reviews` 工作表

## 更新 Apps Script（這一版必做）

1. 打開試算表「擴充功能 → Apps Script」，把 `apps-script.gs` 全部內容貼上取代舊程式碼。
2. 把第 4 行 `PARENT_PIN` 的「請改成家長密碼」改成你的家長密碼，儲存。
3. 「部署 → 管理部署作業 → 編輯（鉛筆）→ 版本：新版本 → 部署」。網址不變。第一次會要求雲端硬碟權限，請允許。

## 注意

- 知道網址的人都能勾選和上傳截圖；確認與刪除需要家長密碼。網址只給小泰福福和家人。
- 截圖會先在手機或電腦上縮小成約 1800 px 的 JPEG 再上傳，單張上限 8 MB。
- `config.js` 已不再使用，可以從 repo 刪除。
