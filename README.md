# 小泰福福 IB 36 分衝刺表

2026/9/20 – 2027/4/25 每日練習進度：英文 A、經濟 HL、化學 HL、物理 SL、數學 AA HL。
模擬考 2027/3/15｜IB 大考 2027/4/26｜成績公布 2027/7/6

打開網頁就能勾選和寫備註，不用登入。進度存在 Google 試算表，任何裝置都看得到同一份。

「每週實體測驗」區：家長把 exam-mate 產生的測驗 PDF 上傳，小泰福福下載列印、限時寫完交給家長批改，家長再把分數和評語填回網頁。PDF 存在你的 Google 雲端硬碟「小泰福福 IB 週測」資料夾，不放在公開的 GitHub。

| 檔案 | 用途 |
|---|---|
| `index.html` | 進度表網頁 |
| `config.js` | 填入 Google Apps Script 網址（只有一行） |
| `apps-script.gs` | 貼到 Google 試算表的程式碼 |

## 設定一次（約 5 分鐘）

1. **建立試算表**：到 Google 試算表新增一份空白試算表，命名「小泰福福 IB 進度」。
2. **貼程式碼**：試算表選單「擴充功能 → Apps Script」，把 `apps-script.gs` 全部內容貼上取代原本的程式碼。
   把第 4 行 `PARENT_PIN` 的「請改成家長密碼」改成你自己的密碼（上傳 PDF、填分數時使用），按儲存。
3. **部署**：右上「部署 → 新增部署作業」→ 類型選「網頁應用程式」
   - 執行身分：**我**
   - 誰可以存取：**所有人**
   - 按「部署」，依畫面授權自己的 Google 帳號（會要求試算表和雲端硬碟權限，用來存進度和測驗 PDF），複製「網頁應用程式網址」（`https://script.google.com/macros/s/…/exec`）。
4. **填網址**：把網址貼進 `config.js` 的引號裡，commit 並 push。
5. **開啟網頁**：GitHub repo 的 Settings → Pages → Deploy from a branch → `main`、`/ (root)` → Save。網址：<https://nokosii.github.io/ibexam/>

之後勾選和備註會出現在試算表的 `progress` 工作表，一天一列，最後一欄是更新時間；測驗清單和分數在 `tests` 工作表。

## 每週測驗怎麼用

1. 在 exam-mate 的 Build Exam 組好一份測驗，產生 PDF 下載到電腦。
2. 打開網頁 → 「每週實體測驗」→「家長模式」→ 輸入家長密碼。
3. 選 PDF、科目、測驗週（預設下一個週六）→「上傳」。也可以直接把 PDF 拖進雲端硬碟「小泰福福 IB 週測」資料夾，檔名開頭寫日期（例：`2026-09-26_經濟.pdf`）。
4. 小泰福福按「下載 PDF」列印作答。檔名以 `a_` 開頭的答案卷只在家長模式出現，學生看不到也下載不到。
5. 批改後在家長模式填分數、評語，按「儲存分數」。

exam-mate 的 PDF 要訂閱 Build Exam：Parents 方案每月 5 份、每份最多 20 題；Teachers 方案每月 10 份。

## 注意

- 知道網址的人都能勾選和下載測驗，所以網址只給小泰福福和家人。上傳和填分數要家長密碼。
- 修改 `apps-script.gs`（包括改家長密碼）後要「部署 → 管理部署作業 → 編輯 → 新版本」才會生效，網址不變。
- 還沒填 `config.js` 時，網頁仍可使用，但進度只存在那台裝置的瀏覽器。
